# CP1404 Practical Reflection

## What have you changed about your process in this subject based on your personal reflection?

I have started breaking each practical into smaller tasks instead of trying
to complete the whole practical at once. I now run and test the program after
each small change. I have also started using separate Git commits for each
completed exercise so that my progress is easier to understand.

## What do you still need to change in terms of your approach, application, time on task, attitude, etc.?

I need to begin the practicals earlier and allocate more time for testing. I
also need to read the entire question before starting so that I do not miss
requirements that appear near the end of an exercise.

## What are you doing well in the subject so far that you will keep doing?

I am using meaningful variable and function names, following the Python style
guide and testing programs with different inputs. I will continue using small
functions and classes to keep each part of a program focused on one job.

## What do you need to stop or change in your work for this subject overall so far?

I need to stop assuming that a program is correct just because it runs once.
I should test normal input, boundary values and invalid input. I also need to
make sure I understand copied example code before adapting it for an exercise.

## What is one request you have or change you suggest for this subject and/or your IT degree overall?

I would find more short class-design examples helpful before larger class
exercises. More examples of useful code-review comments would also help
students provide clearer and more constructive feedback.
